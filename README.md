# The Scottish Ledger

A rated, source-audited register of Scottish invention — 47 claims marked
*granted*, *amended* or *disputed*, plus 8 rejected outright.

Every claim went through an adversarial source check. Where a claim is not
"granted", an examiner's note on the card explains exactly why.

Single self-contained page: fonts subset and embedded, diagrams hand-drawn SVG,
no trackers, no analytics, no network requests at runtime.
